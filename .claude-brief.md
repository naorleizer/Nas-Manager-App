## Verified wire contract (probed live against TrueNAS 25.10.x on 2026-10-30 — trust this over any docs)

Frame shape, `/api/current` (modern) — NOT the legacy `{"msg":"method"}` protocol of `/websocket`:

- Request: `{"jsonrpc":"2.0","id":"<random-uuid-string>","method":"<m>","params":[...]}`.
  `params` MUST be an **array**. `params`-as-object is rejected: `{"code":-32600,"message":"'params' member must be of type array"}`.
- Response: `{"id":...,"result":...}` or `{"id":...,"error":{"code":-32601|−32602,...,"message":"...","data":{"errname":"EINVAL","reason":"..."}}}`.
- Server may interleave notifications without `id` (e.g. `{"method":"collection_update",...}` job
  progress) — never crash on them; ignore or log.
- Keepalive: `core.ping` with `params:[]` returns `"pong"`. Also set OkHttp `pingInterval(20s)`.

### Auth — `auth.login_ex`, one call, on the SAME websocket before any data call

- Password: `params:[{"mechanism":"PASSWORD_PLAIN","username":U,"password":P}]` →
  `result.response_type` ∈ `SUCCESS` | `OTP_REQUIRED` | `DENIED` | `EXPIRED` | `REDIRECT` | `AUTH_ERR`.
  Map: OTP_REQUIRED → "This account requires two-factor authentication.", DENIED → "This account doesn't have API access.",
  EXPIRED → "Account credentials have expired.", REDIRECT → "Authentication must be performed on the active storage controller."
  Anything else → "Invalid username or password."
- API key fallback: after a password-mechanism auth failure, if the secret matches
  `^[0-9]+-[A-Za-z0-9_-]{16,}$` retry once with
  `params:[{"mechanism":"API_KEY_PLAIN","username":U,"api_key":K}]` (verified working; lets users
  paste an API key into the password field with zero UI change).
- Job semantics: right after auth, call `core.set_options` `params:[{"legacy_jobs":false}]`
  (verified: result `{"legacy_jobs":false,...}`) so job-yielding calls return the job id
  immediately, matching the old REST behavior. If it errors -32601 (old server), continue without it.

### Filters — THREE nesting levels

Query filters are positional arg 0: `params = [ <filters-list> ]`, where a filter is
`[column, op, value]`. So the wire JSON for "app named ollama" is
`{"params":[[["name","=","ollama"]]]}`. Verified: two-level nesting throws
`[EINVAL] filters: Value error, Invalid operation: i` / `Invalid filter name` — three-level works.

### Job-yielding calls (app.upgrade / app.start / app.stop — after set_options legacy_jobs=false)

Resolve the call's job id from EITHER completion path, whichever arrives first:
1. Notification `{"method":"collection_update","params":{"collection":"core.get_jobs","msg":"added"|"changed","fields":{"message_ids":[<our-call-id>,...],"id":<jobId>,...}}}` → resolve with `fields.id`.
2. Direct `{"id":<our-call-id>,"result":<number>}` → resolve with that number.
Also cap job calls with a ~15s timeout: if neither arrives (old-style server), fail with a clear
message ("The server didn't acknowledge the task in time.") instead of hanging. The UI keeps its
existing 2s `core.get_jobs` polling (unchanged) once a job id exists.

## Architecture to build

1. `data/network/TrueNasRpcClient.kt` (new): one persistent OkHttp WebSocket per session over the
   derived URI. Callbacks on OkHttp threads complete a `CompletableDeferred` per in-flight id
   (thread-safe map). Lazy connect + `auth.login_ex` on first call after (re)connect. Exponential
   backoff reconnect; in-flight calls fail into `DashboardApiException` after a bounded wait.
   Suspend API like: `suspend fun <T> call(method: String, params: List<Any?>, parse: (JsonElement) -> T, timeoutMillis: Long = 15_000): T`.
   Use Gson `JsonElement` for frames (Gson already a dependency). Special-case job calls per above.
   Map `error` frames to `DashboardApiException` (prefer `data.reason`, else `message`).
2. `data/network/TrueNasUrl.kt`: keep `normalize`/`isHttp`; add
   `deriveWebSocketUri(address: String): String?` — https→`wss`, http→`ws`, preserve explicit port,
   scheme defaults (443/80) when absent, path `/api/current`. Reject/return null on garbage.
3. `data/auth/TrueNasAuthRepository.kt`: `login()` now = build URI from normalized address,
   open a session via the RPC client, `auth.login_ex` per above (PASSWORD_PLAIN, then API-key
   fallback), fill CredentialsStore on success. Distinct messages for OTP/DENIED/EXPIRED/REDIRECT.
   Keep the cleartext-HTTP consent gate EXACTLY as today (http:// ws:// is only after checkbox).
   SSLHandshakeException catch stays, message adapted for wss.
4. `DashboardRepository.kt`: swap every `get/post/postRaw/execute` for RPC calls per the method
   map. KEEP every public suspend signature, every DTO, every extraction function, and the
   `toDashboardResult` error-mapping semantics byte-for-byte. Timeout notes: default 15s;
   service start/stop 130_000ms (server waits up to 120s, mirrors today's serviceControlClient).
   Delete nothing else.
5. `data/network/NetworkModule.kt`: shared OkHttpClient gains `pingInterval(20, SECONDS)` for the
   WS client; keep the plain client for the icon loader untouched (app icons still load via the
   unauthenticated image client + public CDN).
6. `AuthInterceptor.kt` becomes obsolete — remove it and any now-dead references. CredentialsStore
   keeps username+secret (re-auth on reconnect needs both).
7. Tests (all in `app/src/test`): the 751-line DashboardRepositoryTest is pure extraction testing —
   MUST remain untouched and green. ADD: TrueNasUrlTest cases for `deriveWebSocketUri`
   (explicit port, scheme default, http/ws, garbage). ADD a small test for the RPC client framing +
   filter nesting + job-call dual resolution using OkHttp `MockWebServer`'s WebSocket support.
   Do not run them (orchestrator does).
8. `app/build.gradle.kts`: versionCode `5`, versionName `"1.3.0"`. Nothing else changes
   (applicationId `app.nasmanager` stays).
9. Docs: update `README.md` (WebSocket JSON-RPC, `/api/current`, auth.login_ex, ports come from
   the typed address, self-signed-cert note carries over) and add a short `WS_MIGRATION.md` with
   the method map table + probe date. Update `CLAUDE.md` architecture section where it says REST.
